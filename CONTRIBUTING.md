# Contributing support knowledge

Public GitHub Issues is the help and bug tracker for USIPE Office Actions. Search [open and closed issues](https://github.com/jabbertones-cloud/usipe-support/issues?q=is%3Aissue) before filing. Use the [bug report form](https://github.com/jabbertones-cloud/usipe-support/issues/new/choose) for reproducible defects and a concise feature request for improvements.

A useful public report includes the affected MCP tool, safe reproduction steps, expected and observed behavior, a product/client version if known, and a clear verification method. Separate facts witnessed by you from guesses. Keep private account information out.

Agents should read [AGENTS.md](AGENTS.md) and [AGENT-GITHUB-ISSUES.md](AGENT-GITHUB-ISSUES.md), then use the **official GitHub MCP server** with the requesting user's own credentials. Only post new issues or comments when authorized. No test tickets or fabricated acceptance evidence.

Never share unpublished trademark strategy, client names or legal matter contents. GitHub support is not legal advice and cannot extend or file an Office Action deadline.
