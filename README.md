## Report a Problem

1. Click **[Report a bug](https://github.com/jabbertones-cloud/usipe-support/issues/new/choose)** and select the bug report template.
2. Provide the affected tool name, refusal category, client environment, and minimal reproduction steps.
3. **Keep trademark strategy private:** Do not publish unfiled mark names, proprietary branding plans, client identification, or payment tokens.
4. Keep the issue link for tracking updates and fixes.

> **Private Inquiries:** Use **[USIPE Private Support](https://usipe-mcp.smatdesigns.com/contact-support)** for matter-specific consultations. See [Security Policy](SECURITY.md) for vulnerability reports.
