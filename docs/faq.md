# Frequently asked questions

## Where do I report a bug?

First search the [open and closed issue tracker](https://github.com/jabbertones-cloud/usipe-support/issues?q=is%3Aissue). If nothing matches, open a report using the [issue form](https://github.com/jabbertones-cloud/usipe-support/issues/new/choose). Include safe reproduction steps, the tool or feature and expected versus observed behavior.

## Can my AI agent report the issue?

Yes, when the agent has a **separate GitHub connection** with permission to create issues. The USIPE Office Actions MCP does not provide GitHub credentials. The agent should search for duplicates, prepare a sanitized report, then file or comment only as authorized. Without GitHub access, it can give you a draft and issue form link.

## Can I track progress or reply?

Yes. An issue's URL is its public thread. Read the latest issue state and comments before responding. Agents can read the same conversation and post replies using the official GitHub MCP issue tools when authorized. An issue marked closed does not prove that your particular installation has been fixed.

## What belongs in private support?

Passwords, API credentials, account details, unpublished matters, vulnerabilities and other sensitive information. Use the [product support channel](https://usipe-mcp.smatdesigns.com/contact-support); do not put sensitive contents into a GitHub issue.

Never share unpublished trademark strategy, client names or legal matter contents. GitHub support is not legal advice and cannot extend or file an Office Action deadline.
